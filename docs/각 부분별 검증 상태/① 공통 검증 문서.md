# ① 공통 검증 문서

 ## 1. 목적

 Frontend와 Backend에 공통 적용되는 **실행·설정·오류·테스트·빌드 상태**를 검증한다.

```
Application
    ↓
Configuration
    ↓
Execution
    ↓
Logging / Error Handling
    ↓
Testing
    ↓
Build / Environment
```

 ## 2\. 검증 기준

 | 상태 | 의미 |
| --- | --- |
| 🟢 | 검증 완료 |
| 🟡 | 일부 확인 / 추가 검증 필요 |
| 🔴 | 실패 |
| ⬜ | 미검증 |
| ⚪ | 해당 없음 |

## 3. 공통 검증 체크리스트

 | 영역 | Frontend | Backend | 확인 내용 |
| --- | --- | --- | --- |
| Application | 🟢 | 🟢 | 정상 실행 및 기동 |
| Configuration | 🟡 | 🟢 | 환경변수·Port·설정 |
| Execution | 🟢 | 🟢 | 기본 기능 정상 동작 |
| Logging | 🟡 | 🟢 | 로그 및 오류 추적 가능 |
| Error Handling | 🟢 | 🟢 | 오류 상황 정상 처리 |
| Testing | 🟡 | 🟡 | 자동화/수동 테스트 |
| Production Build | ⬜ | ⬜ | Production Build 성공 |
| Environment | 🟡 | 🟡 | 개발/운영 환경 설정 확인 |

## 4\. 핵심 확인 흐름

 ### Frontend

```
Source
 ↓
npm run dev
 ↓
React 실행
 ↓
화면 정상 렌더링
 ↓
Console 오류 없음
```

 ### Backend

```
Source
 ↓
Spring Boot 실행
 ↓
ApplicationContext
 ↓
Tomcat / Port
 ↓
Startup 오류 없음
```

 ### Build

```
Frontend → npm run build → dist/
Backend  → mvnw package  → target/*.jar
```

### 현재 판정
```txt
Frontend
├── Application       🟢
├── Configuration     🟡
├── Execution         🟢
├── Logging           🟡
├── Error Handling    🟢
├── Testing           🟡
├── Production Build  ⬜
└── Environment       🟡

Backend
├── Application       🟢
├── Configuration     🟢
├── Execution         🟢
├── Logging           🟢
├── Error Handling    🟢
├── Testing           🟡
├── Production Build  ⬜
└── Environment       🟡

```
 > **기본 실행 및 동작 검증은 완료되었으며, 자동화 테스트·Production Build·운영환경 설정은 추가 검증이 필요하다.**

 이 정도로 압축하면 **공통 문서의 역할은 유지하면서 Frontend/Backend 상세 검증 문서와 중복도 최소화**할 수 있습니다.
