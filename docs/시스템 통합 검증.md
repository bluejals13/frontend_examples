
 # React + Vite + Spring Boot 학생 관리 시스템 통합 검증 문서

 ## 1\. 목적

 React + Vite 프론트엔드와 Spring Boot + JPA \+ MariaDB 백엔드의 연결 상태를 검증한다.

 검증 범위:

 - React 화면 렌더링
- React Hook → API 모듈 연결
- HTTP/CORS 통신
- 학생 CRUD API
- Spring Boot → JPA → MariaDB
- Actuator Health
- Actuator Metrics
- Browser Network 확인
- 최종 빌드 및 배포 전 검증

---


 ## 6\. Browser Network 검증

 확인된 주요 요청:

```
studentApi.js
 ├── students        200 fetch
 ├── 2               200 fetch
 ├── 2               200 preflight
 ├── 9               200 preflight
 ├── 9               200 fetch
 └── students        200 fetch
```

 의미:

```
preflight 200
    ↓
CORS 허용

fetch 200
    ↓
실제 API 성공
```

 따라서 브라우저 → React → Spring Boot API 통신이 정상이다.

 ## 11\. 다음 배포 체크포인트

 현재 개발환경 검증이 끝났으므로 다음 순서로 진행한다.

```
1. npm run build
       ↓
2. dist/ 생성 확인
       ↓
3. 빌드 오류 확인
       ↓
4. Nginx 정적 파일 서빙
       ↓
5. Nginx /api Reverse Proxy
       ↓
6. Spring Boot 연결
       ↓
7. MariaDB 연결
       ↓
8. 실제 브라우저 CRUD 재검증
       ↓
9. Actuator Health / Metrics 확인
       ↓
10. Cloudflare / HTTPS / 인증서 등 외부 연결
```

 핵심은 **Vite냐 Webpack이냐가 아니라 이 검증 절차 자체**이며, 프론트엔드와 백엔드 모두에서 공통적으로 적용되는 기본적인 개발·검증·배포 사이클이다.
